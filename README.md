# Food Delivery Burger Website

A responsive and modern food delivery burger website built using React.Js and CSS.  
This project focuses on creating an attractive user interface with responsive design and reusable React components.

## Features

- Responsive design for mobile and desktop
- Modern and interactive UI
- Food menu section
- Navigation bar and landing page
- Reusable React components
- Smooth user experience

## Tech Stack

- React.Js
- CSS3

## Installation

Clone the repository:

```bash
git clone https://github.com/NagnathEdake/food-delivery-burger-website.git
```

Move to the project directory:

```bash
cd food-delivery-burger-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```
